
-------------Student Management console Application-------------

The Day 02 task was to create a management console application that could,

⨞ Add Student Information
⨞ Display all students
⨞ Search a student by ID

The  program showcased all these features through the implementation of classes, properties, methods, loops and lists. List is a dynamic data structure which means it does not have a fixed-size.

What did I learn ?
I learned about properties, methods and lists. Handling invalid input(e.g string or char instead of integer) was also a learning opportunity.

Overall, I learned about C# syntax a little more.
